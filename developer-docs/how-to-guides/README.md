# how-to-guides

How-to guides are recipes for contributors who know the basics and have a specific goal. They give the steps in order and explain only where a step would surprise. For a first walk through the code read the [first contribution tutorial](../tutorials/first-contribution.md).

## pages

- [run the tests](run-the-tests.md): run the suite, measure coverage, and run ruff and mypy.
- [add a rule](add-a-rule.md): add a built-in rule and satisfy the tests that every rule must pass.
- [release](release.md): publish a version to PyPI through trusted publishing.
